The first release of PS3SX2, a cover-flow launcher for PS2 games on the PS3 Slim and Super Slim.

![PS3SX2](https://raw.githubusercontent.com/akyelufukhan/PS3SX2/v1.0.0/docs/screenshot.png)

## Highlights

- **Starts `.iso` games on CFW with Cobra, with nothing else installed.** PS3SX2 mounts the
  image as a PS2 disc and the firmware's `ps2_netemu` runs it. Tested on a CECH-2504A.
- **Fixes for about 1,400 games built in.** The community's `ps2_netemu` CONFIG files ship in
  the package and the right one is applied automatically, e.g. Pro Evolution Soccer 6 no
  longer freezes after its intro.
- **Covers download themselves.** When the console is online, missing covers are fetched by
  serial in the background; □ does it on demand. Games without one get a generated cover.
- **3D cover carousel** with title, serial, region and size tags, in English and Turkish
  (picked from the system language).
- **HEN:** `.BIN.ENC` games are loaded into the PS2 Classics Placeholder, and `.iso` games are
  tagged "not playable on HEN".

## Install

Download `ps3sx2.pkg` below, copy it to a FAT32 USB drive and install it with
**Package Manager → Install Package Files → Standard** (enable HEN first if you use HEN).
Put your games in `/dev_hdd0/PS2ISO`. The [README](https://github.com/akyelufukhan/PS3SX2#readme)
has the details.

## Known limitations

- The HEN route (`.BIN.ENC` through the PS2 Classics Placeholder) hasn't been tested on a
  console yet. PS3SX2 can't include the placeholder; install it separately.
- `.iso` games must be on the internal drive; Cobra can't mount PS2 images from USB.
- Split images (`.iso.0`, `.iso.1`, …) aren't supported yet.
- Some games still have issues under `ps2_netemu` that no CONFIG fixes.

No games, firmware, BIOS, Sony files or box art are included. Use games from discs you own.

## Türkçe

PS3SX2'nin ilk sürümü: PS3 Slim ve Super Slim için kapak akışlı bir PS2 oyun başlatıcısı.

### Öne çıkanlar

- **Cobra'lı CFW'de `.iso` oyunlarını başka hiçbir şey kurmadan açar.** PS3SX2 imajı PS2
  diski olarak takar, sistem yazılımındaki `ps2_netemu` da oyunu çalıştırır. CECH-2504A'da
  denendi.
- **Yaklaşık 1.400 oyunun düzeltmesi içinde.** Topluluğun `ps2_netemu` CONFIG dosyaları
  pakette geliyor ve doğru olanı otomatik uygulanıyor; örneğin Pro Evolution Soccer 6 artık
  intro sonrasında donmuyor.
- **Kapaklar kendiliğinden iner.** Konsol internete bağlıysa eksik kapaklar seri koda göre
  arka planda iner; □ ile istendiğinde de indirilebilir. Kapağı olmayan oyunlara kapak üretilir.
- **3D kapak rafı:** başlık, seri kod, bölge ve boyut etiketleriyle; Türkçe ve İngilizce
  (sistem diline göre seçilir).
- **HEN:** `.BIN.ENC` oyunları PS2 Classics Placeholder'a yüklenir, `.iso` oyunlarında
  "HEN'de açılmaz" etiketi görünür.

### Kurulum

Aşağıdaki `ps3sx2.pkg` dosyasını indir, FAT32 bir USB belleğe kopyala ve
**Package Manager → Install Package Files → Standard** ile kur (HEN kullanıyorsan önce HEN'i
etkinleştir). Oyunlarını `/dev_hdd0/PS2ISO` klasörüne koy. Ayrıntılar
[README](https://github.com/akyelufukhan/PS3SX2/blob/main/README.tr.md)'de.

### Bilinen sınırlar

- HEN yolu (`.BIN.ENC` ve PS2 Classics Placeholder) henüz bir konsolda denenmedi. PS3SX2
  placeholder'ı içeremez; ayrıca kurulmalı.
- `.iso` oyunları dahili diskte olmalı; Cobra PS2 imajlarını USB'den takamıyor.
- Parçalı imajlar (`.iso.0`, `.iso.1`, …) henüz desteklenmiyor.
- Bazı oyunların `ps2_netemu`'da hiçbir CONFIG'in düzeltemediği sorunları olabilir.

Pakette oyun, sistem yazılımı, BIOS, Sony dosyası ya da kapak resmi yoktur. Sahip olduğun
disklerdeki oyunları kullan.
